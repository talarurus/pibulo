whoami v0.3.1 refines the website and editor around the existing deterministic agent identity toolkit. The restored homepage design has owner approval at 1440px, 390px and 320px. This is a GitHub source release: `whoami` and `@talarurus/whoami` retain their names, and npm publication remains disabled.

## Refined presentation and customization

- The homepage preserves the large whoami wordmark, two-column desktop composition, unframed interactive avatar, generous whitespace and local installation/live code example. Mobile follows a simple vertical layout. Optional expression thumbnails and identity shortcuts remain available behind disclosures.
- A quiet secondary preview samples an existing three-agent recording through idle → thinking → working → completed. Playback, manual state selection, offscreen/hidden pause and reduced-motion still states expose existing functionality; one contextual link opens Studio Motion mode.
- The editor makes expressions and palettes easier to discover with pose tiles, earlier palette controls, visible hue selection/Auto reset, section navigation that preserves configuration, and a mobile customization jump. Incomplete palette entries can be corrected without losing the editor.
- Component source downloads now return the actual checkout files and helpers. Contrast, selection feedback and responsive fixes are retained. These compositions remain checked-in examples, not separately published component packages.
- README media includes a genuine 5.53-second recording-driven GIF, a static poster, original MP4, importable recording and approved homepage screenshots. Status progression is also written in text.

## Compatibility and scope

No public API, avatar artwork, seed-to-identity mapping, identity fixture, recording format or renderer revision changes. The existing editor controls, SVG/PNG exports, local avatar wall, component examples, experimental manual scenes, Activity/Motion Studio, JSON import/replay and optional MP4 exporter remain available. No new visual library, dependency, framework SDK or monitoring integration is added.

Installation uses a locally built `talarurus-whoami-0.3.1.tgz`. The website and its SVG endpoint bind to loopback; this release does not provide a hosted API or deployed website. Agent activity is simulated or supplied by callers, not automatic agent monitoring or an approval backend. Optional companion scenes remain experimental.

Recorded motion and MP4 were introduced in v0.3.0 and retain their documented contracts: equivalent complete recordings, pinned revisions, origins, policies and timestamps reproduce SVG samples. Browser rasterization, fonts and compressed video bytes remain platform-dependent. MP4 uses runtime-detected WebCodecs H.264, 30 fps, 1..8 agents, even 64..2048 dimensions, a 30-second limit including the ending hold and a 64 MiB cap. No audio, captions, live gaze or animated companion scene export. Reduced-motion behavior and static alternatives remain available.
