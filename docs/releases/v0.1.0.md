whoami v0.1.0 is the first independently buildable GitHub source release. The repository is now public. No package is published to npm and no production website is deployed. This release uses the unchanged original v0.1.0 tag and source.

## Included

- Existing pinned Blobatar generation 2 renderer: ten silhouettes, fourteen expressions and 58 controls, with stable identities preserved.
- Responsive website and editor, eye tracking, click reactions, browser-local wall, composition examples, revisioned sharing and static SVG/PNG export.
- Compiled JavaScript SVG API and React `Face` entry, TypeScript declarations, CSS exports and runnable JavaScript/React examples.
- Six optional experimental manual companion scenes.

## Run and integrate

Use Node 24.21.0 or later within Node 24 and npm 11. Cloning the public repository does not require a GitHub account.

```sh
git clone https://github.com/talarurus/whoami.git
cd whoami
git checkout v0.1.0
npm ci
npm start
# http://localhost:4318 — /editor, /components and /docs
```

After `npm run build`, run `npm run example:react` for http://localhost:4319. `npm pack` creates `talarurus-whoami-0.1.0.tgz`; install that local tarball in a separate application to import `@talarurus/whoami` or `@talarurus/whoami/react`. The package name is not a registry-installation instruction.

## Recorded validation and limits

The original v0.1.0 validation record reports a clean-clone fresh-cache install/build, TypeScript, 17 Node tests, 30 website Chrome checks, separate packed-consumer install/SSR/build/desktop-mobile rendering, exact SVG/PNG pixel parity, retained license/source hashes and hygiene. These are historical v0.1.0 results, not a claim of a new qualification run. See `docs/validation.md` at the v0.1.0 tag.

Browser checks use Chrome and mobile emulation, not physical-device or all-browser certification. PNG exports are static and browser-only. The local server binds to loopback and has no hot reload. Compositions are source examples; `Face` is the packaged React component. Scenes have no real monitoring, approval queue, session tracking, Claude/Codex integration, export or packaged scene API. No other framework/native SDK or hosted service is included. No independent v0.1.0 acceptance review is claimed.
