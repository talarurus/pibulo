# Pibulo v0.3.2

whoami has been renamed **Pibulo**, published by Talarurus: **Little faces. Big personalities.** This is the first GitHub source release under the new product name. The existing public repository was renamed in place to [talarurus/pibulo](https://github.com/talarurus/pibulo); previous GitHub releases v0.1.0–v0.3.1, their tags, notes and historical media remain unchanged.

## Import-path migration

The source-package identifier is now `@talarurus/pibulo`. Replace `@talarurus/whoami` in dependency keys and every import, including subpaths and styles:

```tsx
import {svgFor, identity} from '@talarurus/pibulo';
import {Face} from '@talarurus/pibulo/react';
import {createActivityEngine} from '@talarurus/pibulo/activity';
import {AgentAvatar} from '@talarurus/pibulo/activity/react';
import {parseRecording, serializeRecording} from '@talarurus/pibulo/recording';
import {compileMotionRecording} from '@talarurus/pibulo/motion';
import {RecordedAgentAvatar} from '@talarurus/pibulo/motion/react';
import {exportMP4} from '@talarurus/pibulo/export/mp4';
import '@talarurus/pibulo/motion.css';
import '@talarurus/pibulo/gaze.css';
import '@talarurus/pibulo/react.css';
```

Optional `AgentScene` uses `@talarurus/pibulo/scenes` with `scenes.css` and `motion.css`. All existing export subpaths, signatures and React peer requirements remain the same. Remove the old local dependency when installing the newly built `talarurus-pibulo-0.3.2.tgz` and update imports together. There is no registry alias or redirect package. See the [migration guide](../migration-pibulo.md).

## Preserved behavior and artwork

The approved homepage and Studio retain their layouts and functionality. Avatar geometry, seed mappings, deterministic identities, activity semantics, motion sampling, MP4 export and identity fixtures remain unchanged. Existing version 1 recordings import and re-export without conversion. Compatibility literals remain `whoami-recording`, `whoami-motion-1`, `whoami-mp4-grid-1` and `whoami-motion-cue`; their historical spelling is intentional. Share links and browser storage remain compatible.

Original MIT Blobatar-derived artwork and attribution remain intact: Alain / Alain00/Blobatar, renderer revision `a7fd546ebede49d0a9fa638945b9e534489782a2`, Copyright (c) 2026 Alain. Optional scenes retain SparshKaushik/Blobatarling attribution, maintained by Sparsh Kaushik with additions by Khai. Geist fonts remain SIL OFL 1.1. Original licenses and notices are preserved; the new product name does not imply newly authored avatar geometry or upstream endorsement.

The optional exporter retains pinned MIT `mp4-muxer@5.2.2` and its documented upstream deprecation/maintenance risk. Codec support remains runtime-dependent. No dependency upgrade or new integration is introduced.

## Source distribution

This release is distributed through **GitHub only**, using its normal source archives. Build the source with Node 24.21+ in Node 24 and npm 11, then run `npm pack` to install a local tarball in another application. `private: true` remains set; neither package has been published to npm.

Studio and the SVG endpoint run locally on loopback. Agent events are simulated or supplied by the caller. This release provides no hosted Studio, automatic agent monitoring, transport or approval backend. Existing optional scenes and composition examples retain their documented scope.

Small homepage images, a historical poster and the compatible demo recording are included in the local package. Larger media and historical review records use GitHub references pinned to `v0.3.2`; public access to those URLs must be verified after publication. See [README](../../README.md), [API](../api.md), [motion](../motion-api.md) and [MP4](../mp4-export.md) for installation and existing limits.
